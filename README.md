# Agentic RL 秋招技术面试题库

面向大模型后训练、工具智能体和强化学习研究工程岗位。20 道原创情境题，可组成 A、B 两套试卷。每人两轮，每轮 60 分钟，共答 6 题。

| 使用者 | 从这里开始 |
|---|---|
| 面试官 | [组卷、参考答案与评分标准](面试官手册.md) |
| 候选人 | [技术面试题面](候选人题面.md) |
| 编程题评审 | [Q05–Q08 参考实现与边界测试](面试官编程参考.py) |

需要离线选卷和打印时，[下载完整题库](downloads/Agentic-RL秋招面试题库.zip?raw=1)，解压后用浏览器打开对应的 HTML 文件。向候选人发题时，打开候选人题面，选择本轮试卷后打印为 PDF。完整包包含面试官答案。

在安装了 PyTorch 的 Python 3 环境中运行以下命令，可核对四道现场编程题的样例与边界条件。

```shell
python 面试官编程参考.py
```
