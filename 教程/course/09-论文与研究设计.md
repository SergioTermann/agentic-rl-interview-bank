# 研究加练　把一篇论文变成一个能检验的问题

先读与当前卡点相关的一篇。每篇只交四样：目标函数里的一个设计选择、一项实验对照、一种替代解释、你在小预算下会做的验证。以下阅读顺序按依赖关系排列。

主项目跑完再选读。例如 `zero_group` 长期很高时，优先看动态采样；若你要回答「多试几次才算可靠」，先看 τ-bench 的评估口径。给面试官介绍时说清哪一项已在你的环境里验证，哪一项是读完论文后想做的实验。

| 资料 | 带着什么问题读 | 读完要能做什么 |
|---|---|---|
| 策略梯度、GAE 与 PPO | 哪些项改变梯度期望，哪些项主要改变方差？ | 从 log-derivative 推到 baseline，再推导二步 GAE，解释 PPO 何处裁剪。[策略梯度](https://spinningup.openai.com/en/latest/spinningup/rl_intro3.html) · [GAE](https://arxiv.org/abs/1506.02438) · [PPO](https://arxiv.org/abs/1707.06347) |
| DPO 与 RLOO | 一边给固定偏好对，一边给在线采样回报，两种方法各需要哪些数据？ | 写 DPO 的两条 log-ratio，计算组内留一均值，给各自一个失败场景。[DPO](https://arxiv.org/abs/2305.18290) · [RLOO](https://arxiv.org/abs/2402.14740) |
| DeepSeekMath 与 DeepSeek-R1 | 在可验证推理任务上如何构建反馈？任务变化后还有什么条件成立？ | 找出 GRPO 里同题采样与组内优势的位置；区分 R1-Zero 的 RL 设置与完整 R1 的多阶段训练。将数学题终局判分换成带副作用的工具执行，画出新增接口。[DeepSeekMath](https://arxiv.org/abs/2402.03300) · [DeepSeek-R1](https://arxiv.org/abs/2501.12948) |

| ReAct 与 ReTool | 在什么地方执行外部动作？谁决定何时调用？奖励或示范从哪里来？ | 画出“推理/动作/观测”交替轨迹，对比提示驱动的交互和通过反馈学习工具使用的设置，找一个必须 mask 的外生位置。[ReAct](https://arxiv.org/abs/2210.03629) · [ReTool](https://arxiv.org/abs/2504.11536) |

## 一个完整的阅读示范

以 DAPO 的动态采样为例。若训练组全对或全错，组内回报标准化后奖励优势为零。过滤这样的组，再补采有信号的组，可增加每个优化 batch 内有奖励梯度的样本。代价是额外 rollout，而且被留下的题更可能处于当前策略的中等难度区间。这是一个能改变研究结论的机制。

1. **提出假设。** 给定相同优化步数，动态补采能提高每步有效组比例；给定相同工具调用总数，最终收益可能变小。两个假设应分别检验。
2. **做最小对照。** A 使用固定组数；B 对零方差组补采，记录所有被丢弃轨迹。先用同一真核验奖励、SFT 初值、G、学习率和任务池。不通过调大 B 的生成预算来冒充算法增益。
3. **定义横轴。** 同时画成功率对 optimizer step、生成轨迹数、实际工具调用数的关系。极难题若一直没有有效组，应有尝试上限并记录最终舍弃的题族。
4. **预判会推翻什么。** 若 B 按步数更快，按工具调用数反而落后，论文机制仍能解释更密的更新信号，业务端的优越性则缺少支持。若两者均改善，还要检查题目分布是否改变以及未被过滤的最终评估是否覆盖难题。

## 一页研究设计练习

把查价任务改成“工具有概率超时，允许一次重试”。先写明超时是否消耗预算、读取同一报价是否稳定、任务不可解时怎样计分。接着在下面留一份自己的答案：

| 要填的项 | 示例 |
|---|---|
| 确切命题 | 在固定墙钟预算下，学习选择性重试可提高每小时核验成功任务数 |
| 明确对照 | 永不重试、总是重试、启发式重试和学习策略；共享任务与预生成的外部故障事件 |
| 主指标、成本与切片 | 每小时成功任务、单次成功率、工具次数、P95、按故障率与价格差分层 |
| 替代解释 | 训练策略可能只偏向及时返回的容易任务；按所有分配任务计分并检查跳过率 |
| 停止条件 | 预先锁定预算与开发集，选定配置后只做一次最终比较；若提升来自放弃难题就重写结论 |

**研究岗答辩的最后一问。** “如果给你一周，你最想弄清什么？”可以用已有失败轨迹提出一个足够小的问题，例如“运费变大后，错误究竟集中在总价接近，还是商品价和到手价排序相反的题？”先给两种分桶的分母与错误率，再做反事实。能够说出什么证据会让自己放弃原解释，就是研究判断的一部分。
