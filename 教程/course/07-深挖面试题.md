# 24 道 Agentic RL 深挖面试题

先只读粗体题干，给自己 90 秒作答，再读参考与追问。做第二遍时，把每个回答中的一个数字、一个数据条件或一个终止条件改掉，重新回答。下列情境均为教学设计。

**时间紧先练 8 题。** 第 1、11 题围绕同一条工具轨迹讲梯度与 mask；第 4、6 题用一正一负两个样本手算裁剪和组内优势；第 10、17 题要求拿出自己的失败记录及配对统计；第 18 题拿出重放温度实验的两个 logp；第 24 题只讲自己在这个小环境里真正验证过的结论。答完一题让同伴改一个条件，例如把工具返回换掉、把奖励全设为 1，随后重算。

## 一　策略梯度与目标函数

**1．工具不可微，怎样训练决定调用它的模型？** 写出轨迹概率，把 $\nabla p=p\nabla\log p$ 代入期望，保留模型采样动作的 score。环境只给观测与奖励。追问“工具报价 token 有没有梯度”时，区分预测它的目标损失和通过其输入表示影响后续动作的梯度，在第三课的微型解码器上验证。

**2．为什么减去 $V(h)$ 不会改变期望梯度？把 baseline 设成动作成功率 $Q(h,a)$ 呢？** 给定历史，score 的期望为零，$V(h)$ 可以提出期望。$Q(h,a)$ 依赖采到的动作，通常不能提出。如果 $G$ 的条件期望恰为 $Q$，直接用 $G-Q$ 作权重，期望策略信号就会被抹掉。追问神经网络 baseline 时，补充 actor 更新应切断 baseline 的参数梯度。

**3．GAE 的 $\lambda=1$ 总能得到无偏优势吗？** 完整终止时它望远镜求和成 Monte Carlo 回报减估计价值。回报可无偏估计 $Q^\pi$；当估计的 $V$ 有偏时，数值优势与真实 $A^\pi$ 仍有差。与动作无关的 baseline 不必精确也能保持 on-policy score 梯度的期望。采集器在中途截断又会引入 bootstrap 误差。追问时画两道门并标出下一局的 reset 状态。

**4．负优势 −2，ratio 从 1.1 到 1.5，PPO 是否停止惩罚？** $\epsilon=0.2$ 时目标分别为 −2.2、−3.0。坏动作概率越来越高，梯度仍在。若从 0.8 降到 0.6，裁剪目标停在 −1.6。追问“为什么还监测 KL”，答同一批抽到的单个 surrogate 平台无法约束所有状态和未抽动作。

**5．在相同前缀，old 和 ref 都来自 SFT，它们一直相同吗？** 第一次 rollout 时可能相同。采新一批前发布更新策略后，old 跟随生成版本，ref 可一直冻结。用 ref 做每一批的 ratio 分母，得到的比率没有对应这批行为概率。追问“单条参考 KL 为负”，给出样本 $a$ 在当前概率低于参考概率的例子。

**6．同题奖励为 [0,0,0,1]。把全 batch 一起归一化可以吗？** 本组均值 0.25，总体标准差约 0.433，对应优势约 [−0.577,−0.577,−0.577,1.732]。把不同难度混一起会让全成功的易题也拿正优势，改变相对权重与目标。追问“组归一化无偏吗”，说明自包含均值产生有限组缩放，随机标准差又引入重加权。

**7．提高组大小 G 能治稀疏奖励吗？** 同题独立二元奖励时，可学习到组内差异的概率为 $1-p^G-(1-p)^G$。$p=0$ 时无论 G 多大都没差异。追问“预算固定怎么试”，固定总轨迹数，分别记录非零组比例、覆盖的不同题数、真实成功率和调用开销。

**8．两万对偏好、一千条成功演示、一个昂贵工具 API，你怎么起步？** 先按目标任务建独立评估，用演示 SFT 学格式，偏好有信息时试 DPO；优先把在线预算花在有分歧或能验证的新前缀。若偏好几乎只按答案长度标，先做长度匹配和顺序翻转审计。追问“为什么不能直接比 DPO loss 和 RL reward”，说明量纲、数据分布与估计目标不同，应回共同评估。

**9．拿通过验证器的轨迹再做 SFT，会有什么选择偏差？** 易题和高频解法更易进入样本，失败前缀与恢复行为稀少。按题族记录被选入的比率，用同预算、相同题集的 rejection SFT 对比在线 RL。追问“生成更多一定好吗”，考虑验证器误接收率；搜索次数增大也会增加碰到假阳性的机会。

## 二　Agent 环境、长程任务与评估

**10．模型查了两家却选错，应该改工具奖励还是策略？** 先把原始返回、进入模型的历史、动作映射和独立判分串起来。若数据完整且选错，再定位是价格比较、位置偏好或输出解析。把两家顺序互换并控制价差，有机会区分这几个解释。追问“给每次查询加分”，指出可能奖励重复查询，设计高分失败反例。

**11．为什么不能把整段多轮对话直接当成一句回答做 SFT？** 用户和工具生成的 token 不属于策略动作。它们需作为后续条件输入，loss 只算模型应产生的目标。第一次错误常在角色边界错一位。追问“奖励在最后出现，工具返回能否完全删除”，举一个删去报价后得不到正确决策的反例。

**12．任务超时用零价值 bootstrap 对吗？** 若时间预算就是问题定义，超时是任务终止，可取零；若仅为采集切片且有真实后继观测，可用 $V(h_{\rm next})$，但优势递推不可跨新 episode。追问“后继观测丢了”，指出不能拿下一局初态顶替，修采集器并明确数据处置。

**13．有一笔预算做步骤标注，怎么知道标哪个步骤？** 先从失败分类找常见分歧前缀，例如“已见两家总价仍误选”。固定该处历史，多采样后续比较终局成功概率；优先标不确定且影响大的决策。追问“中间标签升了，终局没升”，检查奖励是否鼓励表面步骤以及评估器是否共用标注偏差。

**14．如何验证 Agent 真的用了工具信息？** 用隐藏报价互换构造配对反事实，保持题面和工具名相同，只改真实工具返回，看最后选择是否随赢家翻转。记录两次查询是否实际成功；打乱工具结果、屏蔽一次返回作负对照。追问“工具调用次数增加”，指出次数只说明动作频率，不能证明模型读取并利用了信息。

**15．模型裁判和人类大体一致，可以直接优化吗？** 在训练分布、策略更新后的分布上分别看假阳性/假阴性；检查顺序、长度、引用形式等偏好。固定人工留出集，盲审高 reward 低 gold 的分歧案例。追问“整体一致率 95%”，构造 95% 都是简单负例而难例全错的情况，要求按题型分层。

**16．N 道题共跑 4N 次，怎样证明系统更可靠？** 明确单次、至少一次命中、四次全对以及实际选择器性能。以同题结果聚合后在任务层统计，不把 4N 次同题尝试当作 4N 个独立任务。追问“无限重试能到 100% 吗”，考虑某题 $p=0$、工具服务共享故障与线上时延预算。

**17．A 从 60% 到 64%，B 说没有统计意义，谁对？** 先要每题配对结果和样本量；4 个百分点是点估计，不足以判定不确定性。按题或家族配对重采样，若随机训练再展示多个种子。追问“二者 95% 区间重叠”，单模型区间的重叠不能替代配对差的区间。

## 三　张量、系统与研究判断

**18．同一 checkpoint 第一批 ratio 中位数为 1，P99 为 8，能开训吗？** 检查尾部集中在哪些 token、worker、角色和模板。锁前缀逐步重算，同步温度、top-p、dropout、KV cache 和 old logp 来源；极罕见浮点差也应量化容差。追问“直接 clip 就好了”，说明裁剪会掩盖分布记录错误，影响优势和诊断。

**19．两个 GPU 分别有 10、90 个有效 token，各自 loss 均值为 1、3，全局均值是多少？** $(10+270)/100=2.8$。直接平均两个均值得 2。追问 DDP 默认平均梯度，若目标是全局 token 均值，应以全局有效数为分母；在默认 world size 平均的实现中，要对局部分子相应乘 world size。注意框架是否已经做缩放。

**20．只剩一晚，rollout 太慢，优先加 GPU 吗？** 用事件时间线定位 prefill、decode、工具等待或验证器。缓存重放同一批工具响应看墙钟变化。工具串行时 GPU 扩容无法移除 51.2 秒的服务下界。追问“开异步”，记录版本滞后与被丢任务的长度分布，同时测成功任务/小时。

**21．同题 8 个 rollout，worker 失败两次，能凑够 8 条重复写入吗？** 以逻辑 sample ID 去重，重试保留尝试记录，按预定义的终止/重新采样规则处理。复制成功样本会改变组均值、方差和独立性。追问“只取回来最快的 6 条”，说明会偏向短、易完成任务，按难度审计被删比例。

**22．训练总损失接近零，模型一定收敛了吗？** 组居中的优势正负对消，ratio 初值为 1 时平均 surrogate 甚至可为零，同一参数上的梯度仍可非零。反之，全同奖组可能真的无奖励梯度。追问“你看什么”，答有效组比例、梯度范数、更新前后策略变化、独立成功率和输出分布。

**23．从 1B 迁移到 7B 后训练 OOM，优先动什么？** 先找是 rollout 还是 learner、长序列还是并发峰值。rollout 看 KV cache、批次与长度；learner 区分激活、参数、梯度和 Adam 状态，再选检查点或分片方案。追问“用 LoRA 就够吗”，解释基座前向、激活与生成 KV cache 仍然有成本。

**24．面试官说规则程序已经 100%，你的项目为什么有意义？** 诚实说明任务已知且小，生产上规则有优势。实验检验独立验证、奖励区分度、同种子对照与 OOD 误差，给出一条规则成功、学习策略失败的轨迹。追问“怎样证明对 LLM 有价值”，提出相同工具环境下的文本策略对照、采样预算和停止条件，并把已经测过的结果与待验证假设分别表述。
